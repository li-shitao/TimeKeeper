# 家庭时光追踪器 App

这是一款移动应用程序，用于记录家庭生活中容易忘记的时间点，例如上次宠物吃药的时间、上次打扫客厅的时间或上次支付电费的时间。它还支持即将发生的事件的提醒和通知。

## 技术栈

*   **前端**: Flutter (用于跨平台的 iOS 和 Android 应用)
*   **后端**: Java 与 Spring Boot
*   **数据库**: H2 (用于本地开发), PostgreSQL (用于生产环境), 以及 SQLite (用于设备端缓存)

## 功能特性

*   查看带有时间戳的事件列表。
*   添加新事件。
*   基本的离线支持 (数据缓存在设备上)。
*   用于管理事件的 RESTful API。

## 用户手册

1.  **启动后端服务器**，具体操作请参见 `backend/README.zh.md` 文件中的说明。
2.  在您的移动设备或模拟器上 **运行 Flutter 应用**，具体操作请参见 `frontend/README.zh.md` 文件中的说明。
3.  应用将打开 **主屏幕**，显示所有已记录事件的列表。如果是第一次运行该应用，此列表将为空。
4.  要 **添加新事件**，请点击右下角的 `+` 按钮。
5.  在“添加新事件”屏幕上，**填写标题和描述**，并选择一个日期。
6.  点击 **“提交”按钮**。您将被带回主屏幕，新事件将出现在列表中。
7.  即使您 **离线**，该应用也能正常工作。它会向您显示上次从服务器同步的数据。您在离线时仍然可以添加新事件，这些事件将在您下次连接到互联网并打开应用时与服务器同步。
